# 에듀 크래프트

브라우저에서 바로 하는 3D 블록 게임입니다. **블록 코딩(빌더봇)** 과 **서바이벌·크리에이티브**를 함께 하고, **지옥(네더) → 엔드 → 엔더 드래곤**까지 도전할 수 있습니다. 「과학 실험-블록 코딩 플랫폼」에서 과학 실험 기능을 빼고 따로 만든 게임입니다.

## 실행하기

| 방법 | 어떻게 |
|---|---|
| 웹 주소 | https://lo4lolo.github.io/edu-craft/ |
| 혼자 하기 | `index.html`을 크롬·엣지·웨일로 열기 |
| LAN 서버 (여러 명) | `서버실행.bat` 실행 → 창에 나온 주소를 같은 와이파이의 다른 기기에서 열기 (파이썬 필요) |
| 방 코드 (여러 명) | 「함께 하기 → 내 방 만들기 → 방 코드로 열기」 (인터넷 필요) |

메인 화면의 **⛏ 서바이벌 / ✨ 크리에이티브** 카드를 누르면 바로 새 세계가 시작됩니다.

## 서바이벌에서 달라진 점

- **자원이 풍부해요**: 광석이 원래보다 1.5~2배 많고 얕게 묻혀 있어요. 땅 위에도 광석 바위가 드러나 있고, 나무도 더 많아요. 시작하면 바로 옆에 **보너스 상자**(원목·사과·빵·횃불·석탄·나무 도구)가 있어요.
- **나무는 밑동만 베면** 맨손이든 어떤 도구든 위까지 한 번에 쓰러져요. (Shift를 누르고 베면 한 칸만)
- **코딩 블록은 재료를 처음 얻으면 열려요**: 처음에는 앞으로·뒤로·돌기·블록 고르기·놓기·말하기만 쓸 수 있고, 판자·석탄·사다리·유리·레드스톤 같은 재료를 처음 손에 넣을 때마다 코딩 블록이 하나씩 열려요. 코딩 창 왼쪽 위에 「열린 코딩 블록 n / 36」이 보여요.
- **빌더봇은 내 가방의 블록을 써요**: 재료가 떨어지면 멈추고 알려 줘요. 치운 블록은 가방으로 들어와요. (되돌리기는 크리에이티브에서만)
- 크리에이티브는 모든 블록·코딩 블록이 처음부터 열려 있어요.

## v1.4: 도전 과제 2판 · 코딩 마스터 · 저사양 최적화

- **도전 과제 72개, 10장**: 첫걸음 → 광부 → 농부와 동물 친구 → 모험가 → 용사 → 지옥과 엔드 → 점프맵 → 전설의 생물 → 빌더봇과 코딩 → 살아 있는 전설.
  - 등급: 일반(1점)·심화(2점)·영웅(4점)·전설(10점). 점수로 칭호 🌱새싹 → 🧭탐험가 → 🔨장인 → 🛡영웅 → 👑전설.
  - 「광석 23/50」 같은 진행 막대, 💡 팁, 먼저 깰 과제(🔒), 숨은 전설(???). 등급이 높을수록 경험치·아이템 보상이 커지고, 전설은 큰 축하 배너가 떠요.
  - 화면 왼쪽 위에 「🎯 다음 목표」. 카드를 누르면 📌 고정. 함께 하기에서 영웅·전설을 깨면 모두에게 알림.
- **🎓 코딩 마스터 22단계, 6장**: 차례대로 → 반복 → 변수 → 조건 → 함수 → 마스터(전설: 나만의 점프맵·효율왕·재귀 나무).
  - 빌더봇이 **실제로 지은 모양**을 검사해요 (일직선, 계단, ㄱ자, 기둥 높이, 네모 테두리, 꽉 찬 바닥, 높이가 다른 기둥, 층이 줄어드는 피라미드, 체크무늬, 재귀 깊이…).
  - 「블록 n개 이하」, 「꼭 써야 할 블록」, 「도형 블록 금지」 조건이 있고, 못 깼으면 모자란 점을 알려 줘요.
  - 진행은 브라우저에 저장돼요(크리에이티브에서도 돼요). 장을 깰수록 빌더봇 색이 바뀌어요(브론즈 → … → 무지개 전설).
  - 22단계를 모두 깨면 **🏅 디지털 배지**(PNG, 닉네임·아바타·달성일·확인 번호)를 내려받을 수 있어요.
- **저사양 최적화**:
  - 설정 「💻 저사양 모드」.
  - 먼 동물은 단순한 모양으로 그려요(LOD). 화질별로 동물·적·파티클 수 한도.
  - 가만히 있는 개체는 충돌 계산을 건너뛰고, 충돌 상자 배열을 다시 써요. 동물 40마리 기준 갱신 비용이 마리당 절반, 그리기도 절반으로 줄었어요.
  - 자동 화질 낮추기에 단계 추가: 나뭇잎·구름 끄기, 시야 3, 해상도 45%. 정글에서 화려한 나뭇잎을 끄면 삼각형이 28% 줄어요.
  - 느릴 때는 청크 만드는 일을 줄여요.

## v1.3: 생물군계 · 동물 · 점프맵

- **새 생물군계**(v1.3 이후 새로 만든 세계만): 정글 · 사바나 · 늪 · 벚꽃 숲 · 메사. 옛 세계는 지은 건물이 어긋나지 않게 지형 그대로.
- **실제 동물**: 말·낙타·기린(길들여 안장 얹고 타기) · 판다 · 앵무새 · 벌(벌집 꿀) · 거북 · 북극곰 · 펭귄 · 개구리
- **상상의 동물**: 유니콘(빠르고 공중 2단 점프, 무지개 갈기) · 불사조(깃털 → 되살아나는 토템) · 구름 양(구름 블록·구름 부츠) · 아기 용(친구가 되면 몬스터에게 불꽃)
- **동물 아이템으로 만드는 것**: 안장, 꿀병·꿀 블록·밀랍·양초·벌통, 거북 투구(물속 숨), 구름 부츠(낙하 피해 없음), 무지개 블록, 불사조 토템, 대나무 비계·막대기, 슬라임 볼 → 점프 발판
- **점프맵**: 출발·도착 발판(⏱ 기록, 코스마다 1~5등), 체크포인트, 점프·대시 발판, 부서지는 발판, 되돌림 블록, 깜빡이 블록 A/B, 크리에이티브 「🏃 점프맵」 탭, 빌더봇 「점프맵 만들기」 블록과 예제 2개. 함께 하기에서 완주하면 모두에게 알림.
- **고친 것**: Shift로 수레에서 못 내리던 문제(원래부터 있던 오류), 빌더봇 미리보기와 실제 짓기의 무작위가 달라지던 문제.

선생님용 명령어 추가: `/parkour` (점프맵 기록), `/parkour reset`, `/summon horse|unicorn|phoenix|cloud_sheep|baby_dragon|…`

## v1.2: 함께 하기 안정화 · 저장 고도화

- **함께 하기(멀티)**: 버전이 다른 기기(예: 웨일은 옛 버전 캐시, 엣지는 새 버전)가 섞이면 "버전이 달라요 → Ctrl+F5" 안내(옛 쪽은 바로 새로고침 제안). 방 코드 연결은 큰 세계도 잘게 나눠 보내고(받는 중 % 표시), 학교 와이파이처럼 기기끼리 연결이 막힌 곳을 위해 중계(TURN) 서버를 더 넣음. 연결 단계(①서버 ②방장 찾기 ③세계 받기)와 실패 이유·해결법을 알려 줌. 끊긴 친구는 75초 뒤 자동 정리. **방장이 다른 창을 봐도 세계가 멈추지 않음.** PeerJS를 못 받으면 예비 주소로. LAN 서버는 느린 기기 하나가 다른 친구를 막지 않게 기기마다 따로 보냄.
- **저장**: 5분마다·직접 저장·나갈 때 **백업**(세계마다 5개, 🕘에서 되돌리기), 지운 세계는 14일 동안 **되살리기** 가능. 세계 목록에 **미리보기 그림**·바꾼 블록 수·저장 공간 표시, ✏ 이름 바꾸기. 파일은 **압축(.educraft)**, 📦 **모두 내보내기**, 여러 파일·**끌어다 놓기** 불러오기(옛 .json 도 됨). 저장 공간이 꽉 차면 안내, 브라우저가 저장소를 지우지 않게 요청. 시크릿 창처럼 저장이 안 되는 곳에서는 경고. **참가자도 「이 세계 사본을 내 기기에 저장」**.
- **소소한 오류**: 채팅에서 한글 조합 중 Enter(마지막 글자 두 번·남음), 방 코드 칸 Enter, 구글 사이트 안에서 저장소가 막힌 브라우저(엣지·웨일 추적 방지)에서 시작이 안 되던 곳, 친구가 처치한 몹 경험치.
- **최적화**: 처음 켤 때 그래픽 성능(내장 그래픽·코어 수)을 보고 알맞은 화질로 시작, 숨겨진 창은 그리지 않고 계산만.

### 멀티가 안 될 때
1. 모두 **Ctrl + F5**로 새로고침해 같은 버전인지 확인(화면 왼쪽 아래 버전 표시).
2. 같은 와이파이인지 확인. 학교 와이파이는 기기끼리 연결을 막기도 해요 → 선생님 노트북에서 **`서버실행.bat`(LAN 서버)** 으로 열고 학생은 그 주소로 접속, 또는 휴대폰 핫스팟.
3. 세계는 브라우저마다 따로 저장돼요(웨일 ↔ 엣지 공유 안 됨). 옮길 때는 💾 내보내기 → 📂 불러오기.

## v1.1에서 더한 것

- **메뉴**: 게임 중 <kbd>Esc</kbd> · <kbd>P</kbd> · 오른쪽 위 「☰ 메뉴」로 일시정지 메뉴. 여기서 「이 세계를 멀티로 열기」, 「다른 친구 방에 들어가기」(혼자 → 멀티), 「방 나가서 혼자 하기」(멀티 → 혼자), 「🏆 도전 과제」.
- **돌·조약돌은 맨손으로도 얻어요** (조금 느릴 뿐). 광석은 여전히 곡괭이가 필요해요. 빌더봇이 치운 블록은 무엇이든 가방으로.
- **원작 요소**: 경험치(구슬·레벨) · 마법 부여대(효율·날카로움·보호·내구성·바다의 행운) · 마을(집·우물·밭·길, 평원·사막·자작나무 숲) · 주민 4직업 에메랄드 거래 · 철 골렘 · 거미 · 늑대(뼈로 길들이기, 저장됨) · 당근·감자·호박·잭오랜턴·수박·버섯·건초 · 낚싯대 · 방패 · 나침반 · 시계 · 경험치 병 · 도전 과제 27개(<kbd>L</kbd>)
- **블록 코딩**: 만약/아니면(감지 조건·식), ~될 때까지 반복, 계속 반복, 코드 멈추기, 함수 만들기·실행하기, 무작위 수, 원·선·복사/붙여넣기·바라보기·부르기. 식에 비교·논리·`random(a,b)`·목록. **👁 미리보기**(테두리 + 필요한 재료), **👣 한 단계씩 실행**, **🏅 코딩 도전 12개**, 블록 복제(⧉), 분류 바로가기, 새 예제 5개.
- **최적화**: 땅속에 묻힌 블록을 메시에서 바로 건너뜀(청크 메시 약 40% 빨라짐), 청크 높이 범위로 화면 밖 판정, 40칸보다 먼 몹은 4프레임에 한 번 계산, 카메라 뒤 개체는 그리지 않음, 빌더봇 상태 창·HUD가 매 프레임 DOM을 새로 만들지 않게, 식은 한 번만 해석해 재사용.

선생님용 명령어 추가: `/xp 숫자`, `/locate village`, `/summon spider|wolf|villager|librarian|smith|cleric|iron_golem`

## 지옥과 엔드

1. **지옥문**: 흑요석으로 가로 4 × 세로 5 틀을 세우고 부싯돌과 부시로 안쪽에 불을 붙여요. 처음 자리 근처의 **무너진 지옥문** 보물 상자에 흑요석과 부싯돌이 들어 있어요. 문 안에 3초 서 있으면 이동해요 (지옥 1칸 = 평소 세계 8칸).
2. **지옥**: 좀비 피글린(먼저 때리면 무리가 화냄), 가스트(폭발 화염구), **지옥 요새**의 블레이즈(블레이즈 막대). 물을 부으면 증발해요.
3. **엔더의 눈**: 엔더맨(밤·엔드)의 엔더 진주 + 블레이즈 가루. 던지면 **엔드 요새** 방향과 거리를 알려 줘요. 요새는 땅속 차원문 방이고, 위에 이끼 낀 돌기둥과 사다리 통로가 있어요.
4. **엔드**: 차원문 틀 12개에 엔더의 눈을 모두 끼우면 열려요. 흑요석 기둥 위 **엔드 수정**이 드래곤을 치료하니 활로 먼저 부숴요. 드래곤을 물리치면 출구 차원문과 드래곤 알이 생기고, 돌아가면 엔딩 화면이 나와요.

선생님용 명령어: `/dimension nether|end|overworld` (차원 이동), `/locate` (엔드 요새 좌표), `/summon blaze|ghast|enderman|zombie_piglin|ender_dragon`.
**함께 하기(멀티) 중에는 차원 이동이 막혀 있어요.** (세계 동기화가 평소 세계 기준이라서)

## 저장

세계는 각 브라우저(IndexedDB `educraft`)에 저장돼요. 지옥·엔드에서 바꾼 블록도 따로 저장되고, 저장한 차원에서 다시 시작해요. 세계 목록의 💾로 파일로 내보내고 「세계 파일 불러오기」로 옮길 수 있어요. 과학 실험-블록 코딩 플랫폼과는 저장소 이름이 달라서 세계가 섞이지 않아요(아바타만 함께 씀).
